# PW / Game CPU Optimizer

> 完美世界竞技平台 / CS2（及其他游戏）CPU 资源隔离优化脚本。  
> 让平台进程不抢游戏 CPU，让游戏跑得更稳更流畅。

---

## ✨ 功能特性

- **🎯 进程自动识别** — 三重判定（路径/进程名/父进程链上溯），不漏任何平台子进程
- **⚡ 平台效率模式** — EcoQoS + BelowNormal 优先级 + 内存 Low 优先级，后台运行不抢 CPU
- **🎮 游戏独占核心** — 平台锁 CPU0-CPU1，游戏独占 CPU2+（可配置掩码）
- **🔄 实时监控补锁** — 进程被游戏/更新程序重置时自动恢复设置（<1 秒内）
- **🌱 零依赖** — 纯 PowerShell + Win32 P/Invoke，不需要装任何第三方模块
- **🖱️ 图形化配置向导** — 原生 WinForms 界面，小白用户也能一键上手
- **💾 JSON 配置持久化** — 下次启动自动加载，支持命令行参数覆盖
- **📊 遥测日志** — 30 秒采样记录 CPU 占用/可用内存，方便赛后复盘卡顿原因
- **🔒 单实例守护** — 重复双击时激活已运行窗口，不会开多个
- **🧠 智能小核保护** — 自动检测 CPU 核数，避免在 4 核以下机器把游戏挤没
- **🎲 多游戏支持** — 改个游戏进程名就能用，不止 CS2

---

## 🧠 工作原理

现代 Windows 的游戏体验卡顿，很大一部分原因是**游戏平台的后台进程**和**游戏本体**在抢 CPU 核心。
